# Round 14 视觉工作台与高级交互设计

日期：2026-07-30

状态：视觉方向已批准，等待书面规格审阅

## 背景

Round 7 已把 RefForge 从基础三栏页面升级为灵感提炼工作台，Round 11-13 又补齐多参考综合、可调整布局和全库备份恢复。当前产品功能链路稳定，但视觉表达仍接近“结构正确的工程界面”：参考卡的图像层次偏弱，工具栏和详情区缺少连续的工作流节奏，比较模式只表现为底部状态条，三栏虽然可调整，仍没有形成一体化的研究桌面。

Round 14 聚焦视觉工作台升级和有明确效率收益的高级交互。它不扩展领域模型，不增加 AI、协作、云同步或公开展示能力，也不改变现有 reference、synthesis、Backup v1、API 或 D1 契约。

## 已批准视觉方向

最终视觉目标保存在：

- `docs/product/assets/round-14-visual-target.png`

融合原则：

- 以第三张概念稿的“观察 -> 可复用原则 -> 避免照搬 -> 转化方向”研究流程为主结构。
- 吸收第二张概念稿的高密度参考卡、字段秩序和紧凑对比区。
- 吸收第一张概念稿的低对比石墨材质、克制边界和连续工作台背景。

目标图用于确定视觉层级、密度、材质和交互表达，不是新增产品能力清单。图中演示数量、缩略图内容、图表形态或标签文字如果与本规格和现有数据模型冲突，以本规格和现有实现为准。

## 目标

- 把现有三栏工作区塑造成连续、安静且可长时间使用的研究桌面。
- 提升参考卡的图像辨识、密度、字段顺序和选中状态。
- 把现有 2-4 条 reference 比较选择升级为可理解、可排序感知的底部对比坞。
- 让右侧详情按来源安全、评分、质量、标签和灵感提炼的顺序快速扫描。
- 增加紧凑度切换、快捷聚焦、渐进展开和明确保存反馈等高级交互。
- 使用原创生成的低干扰工作台纹理提升质感，同时保持文字对比度和加载性能。
- 保持 1600px、1280px、1024px 和 390px 的现有响应式契约与无横向溢出要求。

## 非目标

- 不新增 reference、synthesis、relation 或 Backup v1 字段。
- 不新增 API、D1 migration、媒体上传、R2 或第三方媒体托管。
- 不接入 AI 自动分析、自动打分、自动摘要或推荐。
- 不增加项目、文件夹、团队协作、评论、审批、同步或公开发布。
- 不实现看板拖拽、卡片自由排布、浮动窗口或移动端分栏拖拽。
- 不把概念图中的示例数量、雷达图或缩略图视为真实生产数据。
- 不用装饰性大图、营销 hero、霓虹赛博朋克、玻璃拟态、紫蓝渐变或纯氛围背景替代工作界面。

## 方案比较与决定

### 方案 A：只换主题和背景

保留现有 DOM，仅调整颜色、阴影和纹理。风险最小，但比较模式、卡片密度和详情字段秩序仍显得零散，不能兑现已批准目标图的产品差异。

### 方案 B：视觉系统加聚焦交互

保留现有业务和三栏架构，拆出少量表现组件，升级卡片、工具栏、详情分组和对比坞，并增加设备级紧凑度偏好和快捷聚焦。这能明显提升使用体验，同时不触碰数据层。

### 方案 C：重做为素材资产管理器

引入更复杂的多视图、批量选择、拖拽排序和媒体管理。它会把产品重心从“研究与原创转化”偏向 DAM，也会扩大数据和交互范围。

Round 14 采用方案 B。视觉升级必须服务现有研究流程，而不是借机扩张产品边界。

## 信息架构

### 左侧：研究控制

- 保留品牌、语言、参考/综合稿切换、整理队列和现有筛选。
- 使用紧凑分组、计数和清晰的选中状态，降低连续大表单的感觉。
- 来源安全与质量相关筛选继续可见，不移入隐藏的高级菜单。
- 保留 Round 12 的折叠、恢复、拖拽和键盘调整能力。

### 中间：参考画布

- 工具栏按“搜索 -> 排序 -> 密度 -> 比较/导出 -> 添加参考”排列。
- 搜索是最宽的输入；添加参考是唯一高强调主按钮。
- 卡片使用稳定的 `16:9` 图像区域和紧凑字段顺序：
  1. 资产分类。
  2. 标题与来源。
  3. 授权、公开和质量状态。
  4. 参考价值、可转化性和版权风险摘要。
  5. 最多三项机制、氛围或视觉语言标签。
- 卡片默认使用紧凑密度；用户可在紧凑和舒适两档之间切换。
- 紧凑度只改变卡片尺寸、间距和次要字段显隐，不改变筛选结果、选中项或比较选择。
- 选中、置顶、比较选择和比较上限必须使用不同的形状、图标或文字反馈，不能只靠颜色。

### 底部：临时对比坞

- 仅在现有比较选择模式中出现，不常驻占用画布高度。
- 支持现有 2-4 条有序 reference；按用户选择顺序显示编号、缩略图、标题和移除入口。
- 少于 2 条时明确显示还需选择的数量；达到 4 条后保持现有上限门禁。
- “开始合成”继续进入现有综合稿工作区，不在对比坞内重复右侧详情或综合稿表单。
- 对比坞可折叠为紧凑状态，但折叠不清空选择。

### 右侧：结构化检查与提炼

只读详情按以下顺序组织：

1. 来源与安全。
2. 评分矩阵。
3. 质量清单。
4. 标签轴。
5. 灵感提炼。

“灵感提炼”使用现有字段呈现：

- 观察：`inspiration_points`、结构化灵感条目和拆解笔记。
- 可复用原则：结构化条目的 principle 与可概括的设计规律。
- 避免照搬：`avoid_copying_notes`。
- 转化方向：`transformation_ideas` 和相关原创资产描述。

来源与安全默认展开并始终优先；其余长分组允许折叠。折叠只影响当前页面会话，不写入 D1，也不改变 Backup v1。

## 视觉系统

### 表面与背景

- 基础色使用近黑、石墨、冷灰和偏暖白文字。
- 主背景使用一张原创生成的低对比锻造石墨纹理，最终转换为优化后的 WebP。
- 纹理只用于宽幅工作台底层，不能出现在输入框、卡片正文或需要高对比阅读的表面。
- CSS 必须提供纯色回退；纹理加载失败不能影响布局或可读性。
- 纹理目标体积不超过 `300 KB`，不包含文字、徽标、角色、可识别品牌或第三方素材。

### 层级

- 页面层、面板层、记录卡和临时浮层最多形成四级表面。
- 卡片圆角保持 `8px` 或更小，不创建卡片套卡片。
- 边框优先承担结构，阴影只用于对比坞、对话框和需要脱离文档流的控件。
- Mint 绿色只用于主操作、当前选中、可用安全状态和关键焦点。
- 警告、危险和分类色作为辅助语义，避免页面被单一绿色或蓝色统治。

### 字体与图标

- 延续当前中文优先的紧凑系统字体栈，不引入远程字体依赖。
- 工具表面不使用 hero 尺寸；卡片标题最多两行。
- 熟悉操作使用现有 `lucide-react` 图标；不新增手绘 SVG 或文本符号图标。
- 图标按钮必须有本地化 `aria-label` 和 tooltip。

### 参考图像

- 优先显示 reference 自身合法可用的预览 URL。
- 预览缺失或加载失败时使用克制的分类占位，不伪造具体来源内容。
- Round 14 可以生成一组原创、无品牌、无角色、不可误认为原来源截图的分类研究纹理，作为可选占位资产。
- 占位必须同时显示资产分类或媒体类型文字，不能只靠图像传达含义。

## 高级交互契约

### 密度切换

- 提供“紧凑 / 舒适”二档分段控制或图标控制。
- 默认紧凑，符合研究库快速扫描场景。
- 状态在当前浏览器使用独立的版本化 localStorage key 保存，但不加入 Backup v1；读取失败安全回退为紧凑。
- 两档都必须保持卡片稳定高度策略、标题两行上限和状态可见。

### 搜索快捷键

- 页面未处于输入、文本域、选择器或可编辑区域时，按 `/` 聚焦并选中搜索框。
- `Escape` 只取消当前非破坏性临时层级：先关闭打开的轻量菜单或折叠的对比坞展开态；不丢弃编辑草稿，不删除数据。
- 快捷键提示只在对应控件附近低调显示，不新增教程面板。

### 渐进展开

- 详情长分组使用原生按钮语义控制展开，暴露 `aria-expanded` 和关联区域。
- 来源与安全不允许默认折叠。
- 折叠状态不阻止编辑入口，也不隐藏质量问题总数。
- 动画只使用透明度和小范围位移，持续时间不超过 `180ms`；`prefers-reduced-motion` 下禁用位移和非必要动画。

### 微交互与反馈

- hover 不改变卡片尺寸；最多产生 `1px` 位移或边框增强。
- 选中和比较状态切换不引发网格重排。
- 保存中、已保存、保存失败继续使用现有业务状态，视觉上放在操作区域附近。
- 拖拽分隔条沿用 Round 12 的 Pointer Events、键盘、边界和 localStorage 契约，仅升级视觉反馈。
- 所有按钮、卡片、分隔条和折叠控件保留清晰 `focus-visible`。

## 响应式契约

### 大桌面：`>1280px`

- 保留 Round 12 五轨参考视图和可调整三栏。
- 中间可用宽度达到约 `900px` 时优先显示三至四列紧凑卡片；列数由 CSS 自适应，不硬编码固定四列。
- 对比坞固定在中间工作区底部，不覆盖左侧和右侧滚动内容。
- 各栏内部滚动，页面 body 不产生额外横向或纵向滚动。

### 中等宽度：`821-1280px`

- 不显示桌面分隔条，沿用当前响应式布局。
- 工具栏允许换行，但添加参考和搜索必须保持易发现。
- 对比坞进入中间区域文档流，不遮挡详情。
- 详情继续下置或使用当前既有结构，不引入新的侧滑层。

### 移动：`<=820px`

- 单栏文档流，筛选、卡片、详情和表单无横向滚动。
- 密度控制可以隐藏，移动端固定使用舒适且可触摸的卡片布局。
- 对比坞显示为底部文档流区块或安全的全宽操作区，2-4 条选择可以纵向阅读。
- `390x844` 必须验证中文和英文长标签、对话框、表单、比较模式和详情折叠。

## 组件与模块边界

- `app/page.tsx`：保留业务状态和数据流，只接入新的表现组件与少量会话状态。
- `app/workspace/reference-toolbar.tsx`：搜索、排序、密度、比较、导出和添加入口。
- `app/workspace/reference-card.tsx`：参考卡的紧凑/舒适渲染、选择、置顶和比较状态。
- `app/workspace/comparison-dock.tsx`：2-4 条有序比较选择和进入综合稿动作。
- `app/workspace/reference-detail.tsx`：只读详情的固定字段顺序和渐进展开。
- `lib/workspace-view-preferences.ts`：密度偏好的版本化解析、序列化和安全回退。
- `lib/localization.ts`：新增密度、对比坞、折叠和快捷键提示文案。
- `app/globals.css`：Round 14 tokens、纹理回退、卡片密度、工具栏、详情和对比坞样式。
- `public/art/`：最终选定并优化的项目级生成资产。

拆分只处理 Round 14 会反复修改的视觉单元，不迁移 reference CRUD、筛选算法、综合稿业务或备份逻辑。

## 错误与降级

- 背景或占位资产失败：使用纯色和现有文字占位，无布局跳动。
- 密度偏好损坏或 localStorage 不可用：使用紧凑默认值，不显示阻塞错误。
- 预览图失败：切换到分类占位并保留来源、安全和质量文字。
- 比较中的 reference 因筛选隐藏：继续保留在对比坞；因删除失效时沿用现有业务错误处理。
- 右侧没有选中 reference：显示紧凑空状态，不伪造分析内容。
- reduced-motion：禁用非必要位移、展开动画和平滑滚动。

## 部署与生产验证

- 设计规格和实现计划可在 `main` 留痕；运行时代码从同步后的 `main` 创建 `codex/round-14-visual-workstation` 和隔离 worktree。

- 如需验证比较模式，优先使用现有数据；不得为纯视觉验证长期留下 QA reference 或 synthesis。

## 验收标准

- 实现明显继承批准目标图的结构、密度、材质和研究工作流，而不是只更换颜色。
- 三栏仍可拖拽、键盘调整、折叠、恢复和刷新持久化。
- 工具栏字段顺序稳定，添加参考保持唯一高强调主操作。
- 卡片在紧凑和舒适模式下都能快速识别来源、安全、质量和比较状态。
- 对比坞完整承载现有 2-4 条选择顺序和进入综合稿动作，不复制详情或表单。
- 右侧详情按来源安全、评分、质量、标签和灵感提炼顺序呈现。
- 背景纹理低干扰、可降级、优化后不超过 `300 KB`，且不包含第三方受保护内容。
- 1600px、1280px、1024px 和 390px 无页面级横向溢出、文字重叠或不可达控件。
- 自动化测试、类型检查、lint、构建、视觉比较、本地浏览器和生产只读 QA 均有留痕。

## 风险与控制

- 视觉稿展示了比生产更多的数据：仅继承层级和密度，所有内容由真实现有字段驱动。
- 纹理影响可读性或性能：限制对比度、使用 WebP、控制体积并保留纯色回退。
- 高级交互扩张范围：只实现密度、快捷聚焦、渐进展开和现有比较坞升级。
- `app/page.tsx` 继续膨胀：只拆出 Round 14 视觉单元，不进行无关架构重构。
- 卡片过密导致触控困难：桌面提供两档密度，移动端固定舒适布局。
- 多种状态颜色混乱：状态必须同时使用文字或图标，并由统一 token 管理。
- 视觉回归难自动判断：目标图和实现截图必须使用同一视口并做并排审查，截图不能替代交互验证。
